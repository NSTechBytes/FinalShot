Screenshot Settings

SavePath Default: (empty)
string

Full path including filename and extension where the screenshot will be saved. Supported formats: .png, .jpg, .jpeg, .bmp, .tiff. If empty, captures are silently discarded.

ShowCursor Default: 0
int (0 or 1)

Include the mouse cursor in screenshots and GIF frames. Set to 1 to draw the cursor at its screen position.

ShowNotification Default: 0
int (0 or 1)

Show a themed toast notification with image preview after a successful capture or GIF save.

NotificationSound Default: 1
int (0 or 1)

Play a Windows Media notify WAV when the toast appears (e.g. Windows Notify System Generic.wav). Independent of the Windows sound-scheme Asterisk event, which is often set to silent.

UsePrintWindow Default: 0
int (0 or 1)

Window capture mode for -ws commands. When 1, uses the PrintWindow API for exclusive window capture (no overlapping windows). When 0, uses screen-based capture which may include overlapping content.

JpgQuality Default: 70
int (0-100)

JPEG compression quality. Only applies when SavePath ends in .jpg or .jpeg.

ScreenshotFinishAction Default: (empty)
string

Rainmeter bang or external command to execute after a screenshot is saved. Leave empty for no action.

NotificationClickAction Default: (empty)
string

Rainmeter bang to execute when the user clicks the notification toast body (not the close button). Leave empty for no action.

UITheme Default: 0
int (0-2) or string

Theme for all FinalShot popup windows (notification, encoding progress, state dialog). Accepts: 0 or dark, 1 or light, 2 or system. System mode follows the Windows "Apps use light theme" setting.

Predefined Region

PredefX Default: 0
int

X coordinate (left) of the predefined capture region in screen pixels.

PredefY Default: 0
int

Y coordinate (top) of the predefined capture region in screen pixels.

PredefWidth Default: 0
int

Width of the predefined capture region in screen pixels.

PredefHeight Default: 0
int

Height of the predefined capture region in screen pixels.

Smart Window Snap

DetectWindows Default: 1
int (0 or 1)

Enable Smart Window Snap in -cs custom capture mode. When enabled, the overlay detects visible top-level windows and child controls for instant snap-to-window capture. Set to 0 for drag-only mode.

DetectControls Default: 1
int (0 or 1)

Detect child controls inside windows (toolbars, sidebars, panels, list views, buttons). Has no effect when DetectWindows=0. Set to 0 to detect top-level windows only.

RoundWindowCorners Default: 0
int (0 or 1)

Mask Windows 11 rounded corners on top-level window captures. When enabled, desktop pixels in the sharp rectangle corners are removed (transparent in PNG, black in JPEG). Requires DWM corner preference detection.

GIF Recording Settings

GifSavePath Default: (empty)
string

Full path including filename where the recorded GIF will be saved. If empty, GIF recording commands are aborted.

GifFPS Default: 10
int (1-30)

Frames per second for GIF recording. Values outside 1-30 are clamped.

GifQuality Default: 100
int (0-100)

GIF encode quality. Higher values use more palette colours and stronger dithering for smoother gradients (larger files). Lower values reduce colour count for smaller files. Values outside 0-100 are clamped. Approximate mapping: 85–100 → 256 colours, 65–84 → 128, 45–64 → 64, 25–44 → 32, 0–24 → 16. Dither is disabled below 15.

GifCompression Default: 50
int (0-100)

GIF inter-frame compression. Higher values produce smaller files by coalescing near-duplicate frames and splitting distant dirty regions into multiple bands. Does not change resolution or palette size (use GifQuality for colour fidelity). 0 = exact-frame duplicates only / single dirty rectangle; 50 = balanced; 100 = most aggressive. Values outside 0-100 are clamped.

GifDuration Default: 0
int

Maximum recording duration in seconds. When 0, recording continues until explicitly stopped.

GifPredefX Default: (same as PredefX)
int

X coordinate of the predefined GIF capture region. Falls back to PredefX if not set.

GifPredefY Default: (same as PredefY)
int

Y coordinate of the predefined GIF capture region. Falls back to PredefY if not set.

GifPredefWidth Default: (same as PredefWidth)
int

Width of the predefined GIF capture region. Falls back to PredefWidth if not set.

GifPredefHeight Default: (same as PredefHeight)
int

Height of the predefined GIF capture region. Falls back to PredefHeight if not set.

GifShowOverlay Default: 1
int (0 or 1)

Show the recording overlay with Stop, Pause, and Abort buttons during GIF recording.

GifShowEncodingWindow Default: 1
int (0 or 1)

Show a progress window while the GIF is being encoded and written to disk after recording stops.

GifShowStateDialogs Default: 1
int (0 or 1)

Show a dialog when the user issues a GIF command in an invalid state (e.g. trying to start while already recording, or stopping when not recording).

GifStartAction Default: (empty)
string

Rainmeter bang to execute when GIF recording starts.

GifCancelAction Default: (empty)
string

Rainmeter bang to execute when GIF recording is cancelled (frames discarded).

GifPauseAction Default: (empty)
string

Rainmeter bang to execute when GIF recording is paused.

GifResumeAction Default: (empty)
string

Rainmeter bang to execute when GIF recording resumes from pause.

GifEncodingAction Default: (empty)
string

Rainmeter bang to execute when GIF encoding begins (after recording stops, before encoding completes).

OCR Settings

OcrLanguage Default: en
string

Windows OCR language tag (e.g. en, en-US, de, ja). The corresponding Windows OCR language pack must be installed. Falls back to en if empty or whitespace.

OcrScaleFactor Default: 2
float (1-4)

Upscale factor applied to the captured region before OCR. Higher values can improve recognition of small text. Clamped to 1-4.

OcrSingleLine Default: 0
int (0 or 1)

When 1, OCR result lines are joined with spaces instead of newlines.

ShowOCRWindow Default: 0
int (0 or 1)

Show an editable OCR result window after recognition. The user can edit text, copy to clipboard, then close. When 0, text is silently copied to the clipboard.

OCRFinishAction Default: (empty)
string

Rainmeter bang to execute after successful OCR (not on cancel).

Hotkey Settings

HotkeysEnabled Default: 1
int (0 or 1)

Master switch for global hotkeys. When 0, all Hotkey* chords are ignored. Individual chords must still be set for their respective actions.

HotkeyFullscreen Default: (empty)
string

Global hotkey chord for full-screen capture (-fs). Example: Ctrl+Shift+F.

HotkeyPredefined Default: (empty)
string

Global hotkey chord for predefined region capture (-ps).

HotkeyCustom Default: (empty)
string

Global hotkey chord for custom selection / Smart Window Snap (-cs). Example: Ctrl+Shift+PrintScreen.

HotkeyOCR Default: (empty)
string

Global hotkey chord for OCR text extraction (-ocr). Example: Ctrl+Shift+O.

HotkeyGifToggle Default: (empty)
string

Global hotkey chord for GIF toggle full-screen recording (-gif-toggle).

HotkeyGifToggleSnap Default: (empty)
string

Global hotkey chord for GIF toggle snap recording (-gif-toggle-snap). Example: Ctrl+Shift+G.

Chord format: Parts separated by +. Modifiers: Ctrl, Alt, Shift, Win. Keys: A-Z, F1-F24, PrintScreen, Insert, Delete, Home, End, PageUp, PageDown, Escape, Tab, Space, Enter, Backspace, arrow keys, or hex VK codes (e.g. 0x2C). Matching keys are suppressed by the keyboard hook.

Debug Settings

DebugLog Default: 0
int (0 or 1)

Enable debug logging. When 1, detailed logs are written to the log file for troubleshooting.

DebugLogPath Default: (empty)
string

Custom path for the debug log file. Overrides the default FinalShotDebug.log in the Rainmeter profile directory.

Bang Commands

Bang commands are sent via [!CommandMeasure MeasureName "command"]. All commands are case-insensitive.

Screenshot Commands

-fs Full Screen

Capture the entire virtual screen (all monitors) and save to SavePath.

-ps Predefined Region

Capture the rectangle defined by PredefX, PredefY, PredefWidth, PredefHeight.

-cs Custom Selection

Open the full-screen overlay. Hover to highlight a window or control and click to snap it, or drag to draw a free-selection rectangle. Calls ScreenshotFinishAction after saving.

-ws|windowtitle Window Capture

Capture a specific window by its exact title. The pipe | separator is followed by the window title string. Use UsePrintWindow=1 for exclusive capture.

-ocr OCR Text Extract

Open the snap overlay for region selection, then extract text using Windows OCR. Text is copied to the clipboard and available via GetLastOCRText(). Requires OcrLanguage to be set and the corresponding language pack installed.

GIF Recording Commands

-gif-start Start Full Screen GIF

Start recording a full-screen GIF. Requires GifSavePath to be set.

-gif-start-snap Start Snap GIF

Open the snap overlay for region selection, then start recording a GIF of the selected area.

-gif-start-predefined Start Predefined GIF

Start recording a GIF of the predefined region (GifPredefX, GifPredefY, GifPredefWidth, GifPredefHeight).

-gif-start-window|title Start Window GIF

Start recording a GIF of a specific window by title. The pipe | separator is followed by the window title.

-gif-stop Stop and Save

Stop the current GIF recording and encode/save to GifSavePath.

-gif-cancel Cancel

Cancel the current GIF recording and discard all captured frames.

-gif-pause Pause / Resume

Toggle pause on the current GIF recording. Paused time is excluded from the recording duration.

-gif-toggle Toggle Full Screen

Toggle GIF recording: starts full-screen recording if idle, stops and saves if recording. Ignored if encoding.

-gif-toggle-snap Toggle Snap

Toggle GIF recording with snap overlay: starts snap recording if idle, stops and saves if recording. Ignored if encoding.

-gif-toggle-predefined Toggle Predefined

Toggle GIF recording of the predefined region. Starts if idle, stops and saves if recording.

-gif-toggle-window|title Toggle Window

Toggle GIF recording of a specific window by title. Starts if idle, stops and saves if recording.

Section Variables

Section variables are accessed via [&MeasureName:FunctionName()]. Requires DynamicVariables=1 on the referencing meter.

GetStatus() Returns: string

Returns the numeric recording state: 1 = Idle, 2 = Recording, 3 = Encoding.

IsRecording() Returns: string

Returns 1 if currently recording, -1 otherwise.

IsEncoding() Returns: string

Returns 1 if currently encoding, -1 otherwise.

IsIdle() Returns: string

Returns 1 if idle (not recording or encoding), -1 otherwise.

IsPaused() Returns: string

Returns 1 if recording is paused, -1 otherwise.

GetFrameCount() Returns: string

Returns the number of frames captured so far in the current recording. Returns 0 when not recording.

GetElapsedTime() Returns: string

Returns the elapsed recording time as MM:SS (excludes paused time). Returns 00:00 when not recording.

GetElapsedSeconds() Returns: string

Returns the elapsed recording time in whole seconds (excludes paused time). Returns 0 when not recording.

GetSavePath() Returns: string

Returns the full path of the last successfully saved GIF file. Returns "" if no GIF has been saved yet this session.

GetLastFileSize() Returns: string

Returns the file size of the last saved GIF as a human-readable string (e.g. 2.4 MB, 512 KB, 980 B). Returns "" if no GIF has been saved yet.

GetLastOCRText() Returns: string

Returns the last OCR result text. Empty if none, cancelled, or failed. After ShowOCRWindow=1, this reflects any edits made in the result window.

Default measure string: When the measure is referenced without a function name (e.g. [&Measure_FinalShot]), it returns the current status: Idle, Recording, or Encoding.

Example: Complete Measure

[MeasureFinalShot]
Measure=Plugin
Plugin=FinalShot

; Screenshot
SavePath=#@#Screenshots\shot.png
ShowCursor=1
ShowNotification=1
NotificationSound=1
UsePrintWindow=0
JpgQuality=85
ScreenshotFinishAction=[!Log "Screenshot saved"]
UITheme=0

; Predefined Region
PredefX=200
PredefY=150
PredefWidth=1024
PredefHeight=768

; Smart Window Snap
DetectWindows=1
DetectControls=1
RoundWindowCorners=0

; GIF Recording
GifSavePath=#@#Screenshots\recording.gif
GifFPS=10
GifQuality=100
GifCompression=50
GifDuration=0
GifShowOverlay=1
GifShowEncodingWindow=1
GifShowStateDialogs=1
GifStartAction=[!Log "GIF recording started"]
GifStopAction=[!Log "GIF recording stopped"]

; OCR
OcrLanguage=en
OcrScaleFactor=2
OcrSingleLine=0
ShowOCRWindow=1
OCRFinishAction=[!UpdateMeter MeterOCR][!Redraw]

; Hotkeys
HotkeysEnabled=1
HotkeyCustom=Ctrl+Shift+PrintScreen
HotkeyOCR=Ctrl+Shift+O
HotkeyGifToggleSnap=Ctrl+Shift+G

; Debug
DebugLog=0
