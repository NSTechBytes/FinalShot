# FinalShot

FinalShot is a free, open-source [Rainmeter](https://www.rainmeter.net/) plugin for capturing screenshots, recording animated GIFs, and extracting text with OCR—directly from your skins.

Trigger captures with bangs or global hotkeys, choose full screen, region, window, or smart snap selection, and style the built-in UI to match your desktop with Dark, Light, or System themes.

## Documentation

Everything you need to install and configure FinalShot lives on the docs site:

**[Documentation & installation guide](https://nstechbytes.github.io/FinalShot/)**

There you’ll find the full API reference, settings, bang commands, section variables, and example skins.

## Features

- **Screenshots** : full screen, predefined region, custom selection, and window capture  
- **GIF recording** : snap, full screen, predefined, or window modes, with pause/stop overlay and encoding progress  
- **OCR** : select a region and copy recognized text (optional edit window)  
- **Hotkeys** : optional global shortcuts that work outside Rainmeter  
- **Notifications** : themed toasts with optional sound and click actions
